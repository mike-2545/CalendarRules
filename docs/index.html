Open-source Google Calendar integration for Universal Devices

Your calendar sets the schedule. Your ISY decides what to do.

CalendarRules reads events from Google Calendar and uses rules to update existing IoX type-2 state variables. Write your own ISY programs for lights, HVAC, notifications, or anything else—CalendarRules does not control equipment directly.

Simple rules, existing automation

Google Calendar (read-only) → Title / location rules → Time offsets → Existing IoX state variables → Your ISY programs

Match the event

Use keywords and matching options for an event's title or location. Select calendars you want to read.

Choose the timing

Start a variable early or end it later with independent minute offsets. Overlapping events are evaluated together.

Keep control in IoX

Map each rule to an existing state variable. Your ISY programs determine the physical actions.

Safety is intentional. Untrusted or incomplete calendar information does not automatically mean “everything OFF.” An already-ON variable can retain its value if the plugin stops, authorization is lost, or the license expires. Use independent fail-safe logic for equipment.

Getting started

CalendarRules v0.4.12 is in Beta. It has been tested on multiple eisy installations, but additional OAuth, update/restore, and complete event-lifecycle testing remains. Please test with an isolated state variable first.

1. Install

Find CalendarRules in the Universal Devices eisy-ui Plugin Store and activate an available Beta edition.

2. Authorize and configure

Use Google Authenticate, add calendar IDs, and create rules mapped to existing IoX type-2 state variables.

3. Build your ISY programs

Verify the schedule and variable readback before connecting any real-world automation.

Calendar compatibility

Already using Outlook or Apple Calendar? You can keep your familiar scheduling tools. CalendarRules reads Google Calendar, so the events you want to automate must be available on a Google Calendar that the authorized account can access. CalendarRules does not sync Outlook or iCloud calendars itself.

Microsoft Outlook

gSyncit can synchronize classic Outlook calendars with Google Calendar. It does not support the new Outlook interface. OneCal is another option for connecting Outlook and Google calendars.

Apple Calendar app

If you schedule on a Google account through Apple's Calendar app, you may not need a sync service at all. Add your Google account and ensure the event is saved to a Google calendar, not an iCloud or local calendar.

Apple iCloud Calendar

If your events live in iCloud, a service such as OneCal can synchronize them into Google Calendar. Confirm that the event's title, location, start time, and end time are preserved as needed for your rules.

Check the destination calendar, not just the calendar app. Displaying Outlook or iCloud events alongside Google events is not the same as making those events available to CalendarRules. Verify a test event appears in Google Calendar under a calendar the plugin reads. One-way synchronization into Google is often enough; two-way sync is optional. Sync and subscription delays can affect time-sensitive automations, so test changes and cancellations and provide appropriate fallback logic.

These third-party products are examples, not endorsements or required integrations. They are not developed, supported, or controlled by CalendarRules. Check current compatibility, pricing, privacy, and synchronization frequency with each provider.

Google Calendar data and privacy

CalendarRules requests Google Calendar read-only access to obtain scheduled events. The plugin uses selected event titles, locations, and times to evaluate rules. It stores a local schedule cache to support evaluation through temporary network interruptions; OAuth credentials are managed through the eisy-ui platform's protected integration.

Read the full CalendarRules privacy policy for details on access, storage, sharing, retention, and revocation.
